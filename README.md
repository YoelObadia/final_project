Steps to run the project:

1-> in the files create_database.js and server.js, enter the mysql connection details
2-> in the terminal at the path: .../final_project, run the cmd node create_database.js
3-> check if all 9 tables are successfully added and full in the database
4-> in the terminal at the path: .../final_project/src, run the cmd npm start
5-> when the project is opened, split the terminal and in the same path run the cmd node server.js
6-> the server is now running and the project is ready to be used

If node cmd doesn't work, make npm install before the previous steps.
